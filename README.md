# Ritim Kaşifleri Runtime

Bu depo yalnız production dağıtımı için derlenmiş runtime artifact'lerini içerir.
Ana kaynak kodu private bingoweb/maarif-matematik-oyunlari deposundadır.

Artifact'ler Git commit SHA ile isimlendirilir ve yanlarında SHA-256 manifesti bulunur.
Hiçbir API anahtarı, SSH sırrı veya öğrenci verisi bu depoda tutulmaz.
